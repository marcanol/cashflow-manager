# UI Principles

## Tone
Minimal, calm, plain-language, action-oriented.

## Avoid
- accounting jargon where ordinary language works
- dense dashboards
- excessive cards
- pie-chart-heavy budgeting screens
- configuration-first UX
- navigation depth
- decorative complexity before workflow validation

## Initial information architecture
### Today
- Safe-to-Spend
- next paycheck
- current balances
- reserved funds
- upcoming obligations
- Things That Need You

### Plan
- chronological cash-flow timeline
- paycheck events
- reserve movements
- recommended payments
- planned late fees
- projected lowest balance

### Transactions
- bank activity
- suggested matches
- exceptions
- internal transfers
- reconciled history

### Bills
- recurring obligations
- current-month occurrences
- payment policy
- late-fee/grace rules
- source/account

### Settings
- accounts
- income schedules
- buffers
- integrations
- household context periods
